# Seguridad / Security

## Reportar una vulnerabilidad

Si encuentras una falla de seguridad en expense me, **no abras un issue público**. Escríbenos a
**hello@otherwisetech.com** con el asunto "Seguridad: expense me" e incluye la versión (Acerca de),
tu versión de macOS y los pasos para reproducirla. No envíes datos personales ni financieros reales:
si hace falta un archivo, usa uno de ejemplo inventado.

Te responderemos lo antes posible, te contaremos qué vamos a hacer y te avisaremos cuando la
corrección esté publicada. Te pedimos no divulgar la falla hasta entonces.

Versiones con soporte: la última versión publicada en
[Releases](https://github.com/otherwisetech/expense-me-releases/releases).

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Email **hello@otherwisetech.com** with
the subject "Security: expense me", the app version (About), your macOS version and the steps to
reproduce it. Never send real personal or financial data; use a made-up sample file if one is
needed. We will reply as soon as we can and let you know when a fix is released; please keep the
issue private until then. Only the latest release is supported.
